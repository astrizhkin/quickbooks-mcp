# Tools

Generated by `quickbooks-mcp --tools-reference` from the registered tools; do not edit by hand (a test fails if it is out of date).

**64 tools** with everything enabled: 41 read, 3 payroll (`--allow-payroll`), 20 write (`--allow-writes`).
By default only the read tools are registered. Every tool accepts only what is listed here; unknown values are refused with a message.

## Account Tax Line

## Purchase Write

### `create_purchase_transaction`

Create a purchase or banking transaction (bill, bill payment, purchase order, item receipt, vendor credit, check, credit card charge or credit, sales tax payment, transfer, journal entry). Use describe_write_fields to see the field names; set dryRun to preview the request without sending it.

Needs: `--allow-writes or QB_ENABLE_WRITE`. Example: *"Enter a bill from Acme Supply for $250 dated today."*

| Parameter | Type | Description |
|---|---|---|

| `data` * | any | Fields by qbXML element name, e.g. {"Name":"Acme","BillAddress":{"Addr1":"1 Main St"}}. References are {"FullName":"..."} or {"ListID":"..."}; repeated elements (lines) are arrays. |

## Write Schema

### `describe_write_fields`

List the field names accepted by create or update for an entity, as a tree. Empty text is a plain value, [..] is a repeatable element, nested objects are groups such as addresses and lines, and a value like 12.0+ means that field needs qbXML 12.0 or a newer QuickBooks.

Needs: any write switch. Example: *"What fields can I set when creating an invoice?"*

| Parameter | Type | Description |
|---|---|---|
| `entity` * | string | Entity name, e.g. Customer, Invoice, Bill, JournalEntry. |
| `operation` | string | create (default) or update. |

\* required
