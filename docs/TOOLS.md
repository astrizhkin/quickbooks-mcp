# Tools

Generated by `quickbooks-mcp --tools-reference` from the registered tools; do not edit by hand (a test fails if it is out of date).

**50 tools** with everything enabled: 30 read, 2 payroll (`--allow-payroll`), 18 write (`--allow-writes`).
By default only the read tools are registered. Every tool accepts only what is listed here; unknown values are refused with a message.

## Batch Write

### `create_records`

Create up to 50 records in one call. Each item is {entity, data, idempotencyKey?}. Items run in order; by default a failed item does not stop the rest, and every item gets its own result. Give each item an idempotencyKey so a retry of the whole call cannot duplicate.

Needs: `--allow-writes or QB_ENABLE_WRITE`. Example: *"Create these five customers from my list, and don't create duplicates if I ask again."*

| Parameter | Type | Description |
|---|---|---|
| `items` * | any | Array of {"entity": "Invoice", "data": {...}, "idempotencyKey": "..."}. |
| `dryRun` | boolean | true to preview every item and send nothing. |
| `stopOnError` | boolean | true to stop at the first failure. |

\* required
