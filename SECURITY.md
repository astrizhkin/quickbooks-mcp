# Security Policy

## Reporting a vulnerability
Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/devwithmj/quickbooks-mcp/security/advisories/new).
Do not open a public issue. Expect an initial reply within a few days.

## Scope
This server can read, and optionally write, financial data. Reports about write-gate bypass, prompt-injection paths, data leakage or unsafe handling of company files are especially welcome.
Do not include real company data in a report.
