Ask your AI about QuickBooks Desktop.

An open-source MCP server that lets Claude and other AI apps read your QuickBooks Desktop books on your own Windows PC. Read-only by default. Nothing leaves your computer except what the assistant is shown.

Download GitHub User guide

QuickBooks Desktop Pro, Premier, Enterprise Windows MIT license Not for QuickBooks Online

What it does

Answers questions

Customers, vendors, items, invoices, bills, inventory, time, and every standard report: aging, profit and loss, balance sheet and more, as tidy tables.

Makes changes only if you allow it

Creating, updating, deleting and voiding are separate switches. Previews, your approval for deletes, idempotency keys, and an audit log.

Safe by default

Read-only. Tax IDs, bank and card numbers masked. Payroll off. Card data never accepted. Text in your records is treated as data, not instructions.

Local

Runs next to QuickBooks through its own SDK. No cloud, no account, no telemetry.

Install

Pick one.

Claude Desktop: download the .mcpb from the latest release and open it.

Any MCP app, with Node.js:

npx -y @devwithmj/quickbooks-mcp

With .NET 10:

dnx DevWithMJ.QuickBooks.Mcp --yes

Or run quickbooks-mcp-win-x64.exe from the release (use -win-x86 if QuickBooks is 32-bit only).

Package listings (npm, NuGet, the MCP Registry) go live with the first tagged release; until then use the GitHub release or build from source.

Set up in five minutes

  1. Open your company file in QuickBooks as an Admin, in single-user mode.
  2. Run the server once with --authorize and choose Yes, always; allow access even if QuickBooks is not running in the dialog QuickBooks shows.
  3. Add the server to your AI app (the guide has the exact snippet for Claude Desktop, Claude Code, VS Code and Cursor).
  4. Ask: "Show accounts receivable aging and the three customers who owe the most."

Trouble? Run --doctor; the guide maps every message to a fix.
